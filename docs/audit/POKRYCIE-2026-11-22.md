Potwierdzenie testowe:

Pozostaje:

## Jak odtworzyć raport

1. `npm run test:tap`
2. `node tests/extended-browser.mjs > artifacts/extended-browser.log`
3. `npm run coverage:report`

Raport wymaga istniejących plików implementacji i wyniku TAP. Brak pasującego testu jest ujawniony, a nie liczony jako potwierdzona reguła. Dzisiejsza data wygenerowania nie oznacza nowego zatwierdzenia źródła.
